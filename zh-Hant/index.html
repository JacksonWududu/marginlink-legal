隱私政策

MarginLink 由個人開發者 yanhao wu 提供。我們盡量在你的 Mac 上處理閱讀內容；播客搜尋、節目資源和音訊播放需要連線至相應的第三方。本文說明應用程式和法律文件網站各自處理資料的方式。

隱私聯絡信箱：BloatMonster@163.com。

1. 本機閱讀資料

你選擇匯入 EPUB 或 PDF 後，應用程式會將原文複製到自行管理的本機書庫，不會修改你選擇的來源檔案。應用程式會儲存書名、作者、格式、原始檔名及閱讀所需的資訊，並以 SHA-256 識別文件。SHA-256 用來識別內容，並非檔案加密。

畫線、引文、筆記、主題、顏色、原文定位、建立和修改時間、閱讀位置、進度及介面偏好設定都儲存在本機。目前的應用程式沒有將書庫、原文或筆記上傳至開發者伺服器的功能，也沒有應用程式帳戶或由應用程式提供的雲端同步功能。

掃描 PDF 的文字辨識透過本機 Apple Vision 進行。辨識頁面會在本機處理；你儲存的引文和定位資訊可以成為本機筆記的一部分。

2. 圖片與收藏牆

你為收藏牆選擇的圖片會以原始檔案及縮圖等形式儲存在本機。原圖可能保留 EXIF 等中繼資料，包括圖片原本含有的拍攝位置；應用程式不保證清除這些中繼資料。掛畫替換和還原功能可能保留上一張圖片，供你還原。

這些圖片不會透過目前的應用程式上傳給開發者。你自行分享、匯出或透過系統備份儲存資料時，相關處理方式取決於你選擇的工具和服務。

3. 播客搜尋與資源請求

播客功能會發出以下網路請求：

  • 搜尋時向 Apple iTunes 目錄傳送搜尋詞和所選的目錄地區；透過 Apple 播客連結尋找節目時，傳送節目 ID 和地區。
  • 預覽或開啟節目時，向節目發布者或其服務供應商請求 RSS、封面及相關資源。預覽本身也可能在本機儲存節目和單集檔案。
  • 讀取節目文字時，請求發布者提供的公開逐字稿；播放時，向媒體託管方請求音訊。資源請求可能經過第三方重新導向或 CDN。

目錄地區用來選擇搜尋目錄，預設值可根據介面語言或系統地區推導；這項功能不使用 GPS 定位。接收請求的第三方服務供應商通常可以看到連線 IP 位址、請求時間、資源位址，以及請求中攜帶的搜尋詞、地區或節目 ID。應用程式的播客用戶端也會傳送應用程式識別資訊和播放所需的音訊範圍請求；目前的實作不會附帶書庫、筆記或圖片，也不會附加登入 Cookie 或 Authorization 請求標頭；發布者提供的資源 URL 本身可能包含存取簽章或權杖。

第三方可能據此得知你請求過哪些節目或單集。各方獨立處理資料的方式和保留期限由各自的政策決定，本應用程式無法控制或保證。Apple 的處理方式請見 Apple 隱私政策；其他節目和媒體服務供應商則以各自公布的政策為準。

你可以選擇不使用播客功能；需要連網的功能在離線時將無法完整使用。

4. 播客的本機記錄與暫存音訊

節目和單集資訊、資源 URL、公開逐字稿全文、播客筆記、播放位置、音量和部分選擇狀態都會儲存在本機，封面也會在本機快取。將播客項目從收藏牆移除，不等於刪除對應的收聽記錄和筆記。

在支援的 macOS 版本上，文字時間校準使用本機音訊及已安裝的聽寫語言資源，透過系統 SpeechAnalyzer 處理。目前的實作不會為此請求雲端辨識或下載語音模型。校準可能下載一集音訊並產生暫存轉換檔案；正常結束工作或關閉播放載入器時，會清理相應的暫存檔案，異常結束可能留下殘留檔案。

5. 分析、診斷和安全

目前的應用程式沒有內建廣告 SDK 或分析 SDK，也沒有向開發者自動傳送使用統計或當機報告的實作。應用程式和系統可能在本機記錄執行錯誤等診斷資訊；你透過系統設定允許 Apple 蒐集的診斷、商店記錄和你自行傳送的資料，分別受相應設定及政策約束。

應用程式限制書籍中的指令碼、遠端資源和任意檔案路徑存取；閱讀所需的核心執行函式庫隨應用程式在本機提供。播客請求則另行存取外部服務。這些措施不代表絕對安全。本機資料沒有應用程式層級的加密；裝置權限、磁碟加密和備份由你及作業系統管理。

6. 儲存、刪除與資料遺失

閱讀和播客資料主要儲存在應用程式管理的本機儲存空間。你可以在介面中逐條刪除書籍筆記或播客筆記。目前版本沒有提供涵蓋所有書籍和播客檔案的一鍵清空入口；解除安裝應用程式也不應被視為已刪除全部支援檔案、暫存檔案或系統備份。

目前的實作遇到本機書庫索引無法解析或內容驗證失敗時，會清空並重建書庫，可能刪除同一儲存目錄中的書籍、播客和收藏牆資料。因此，應用程式無法保證資料會一直保留到你主動刪除；請為重要原文和筆記另外保留副本。

需要完整清理本機資料時，請先結束應用程式，再依實際安裝環境管理應用程式支援檔案和暫存檔案；如有不確定之處，可透過本文信箱聯絡我們。開發者無法遠端存取或刪除僅存在於你的裝置或個人備份中的資料。撤回檔案選擇授權不會自動刪除已匯入的副本；需要停止播客對外連線時，請完全結束應用程式。

7. 主動聯絡開發者

如果你寄送電子郵件，我們會收到你的電子郵件地址、內文及你主動附加的檔案，並用來回覆、排查問題或處理請求。請勿傳送無關的書籍全文、敏感筆記或個人照片；可優先提供合成範例。郵件也會經過你和開發者使用的電子郵件服務供應商。

聯絡資料僅在處理請求所需的期間或適用法律要求的期間內保留。你可以透過本文信箱查詢、更正或請求刪除開發者持有的聯絡資料；如依法需要保留，我們會說明相應情況。

8. 法律文件網站

本網站本身不加入分析指令碼、廣告、登入系統、追蹤 Cookie 或外部字型。網站計畫使用 GitHub Pages 託管；當你造訪該託管版本時，GitHub 會基於安全目的記錄並儲存訪客 IP 位址，具體處理方式請見 GitHub Pages 資料說明和 GitHub 隱私聲明。這與應用程式本機書庫的資料處理是兩件事。

9. 政策更新與聯絡

功能或資料處理方式變更時，我們會更新本頁。簡體中文、繁體中文和英文版本應保持相同內容；如發現表達不一致，請聯絡我們確認。隱私問題或請求請寄至 BloatMonster@163.com，收件人為 yanhao wu。
