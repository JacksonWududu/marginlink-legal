隐私政策

MarginLink 由个人开发者 yanhao wu 提供。我们尽量在你的 Mac 上处理阅读内容；播客搜索、节目资源和音频播放需要连接相应第三方。本文说明应用和法律文档网站各自的数据处理方式。

隐私联系邮箱：BloatMonster@163.com。

1. 本地阅读资料

你选择导入 EPUB 或 PDF 后，应用会把原文复制到自己管理的本地书库，不修改你选择的源文件。应用保存书名、作者、格式、原始文件名及阅读所需的信息，以 SHA-256 标识文档。SHA-256 用于识别内容，不是文件加密。

划线、引文、笔记、主题、颜色、原文定位、创建和修改时间、阅读位置、进度及界面偏好保存在本机。当前应用没有把书库、原文或笔记上传到开发者服务器的功能，也没有应用账户或应用提供的云同步功能。

扫描 PDF 的文字识别通过本机 Apple Vision 进行。识别页面在本地处理；你保存的引文和定位信息可以成为本地笔记的一部分。

2. 图片与收藏墙

你为收藏墙选择的图片会以原始文件及缩略图等形式保存在本机。原图可能保留 EXIF 等元数据，包括图片本来含有的拍摄位置；应用不保证清除这些元数据。挂画替换和恢复功能可能保留上一张图片，以便恢复。

这些图片不通过当前应用上传给开发者。你自行分享、导出或通过系统备份保存资料时，相关处理取决于你选择的工具和服务。

3. 播客搜索与资源请求

播客功能会发起以下网络请求：

  • 搜索时向 Apple iTunes 目录发送搜索词和所选目录地区；通过 Apple 播客链接查找节目时发送节目 ID 和地区。
  • 预览或打开节目时，向节目发布者或其服务商请求 RSS、封面及相关资源。预览本身也可能在本机保存节目和单集档案。
  • 读取节目文字时，请求发布者提供的公开转录；播放时向媒体托管方请求音频。资源请求可能经过第三方重定向或 CDN。

目录地区用于选择搜索目录，默认值可根据界面语言或系统地区推导；这项功能不使用 GPS 定位。接收请求的第三方服务商通常可以看到连接 IP 地址、请求时间、资源地址，以及请求中携带的搜索词、地区或节目 ID。应用的播客客户端还发送应用标识和播放所需的音频范围请求；当前实现不附带书库、笔记或图片，也不附加登录 Cookie 或 Authorization 请求头；发布者提供的资源 URL 本身可能包含访问签名或令牌。

第三方可能据此了解你请求过的节目或单集。其独立处理方式和保留期限由各自政策决定，不能由本应用控制或保证。Apple 的处理方式见 Apple 隐私政策；其他节目和媒体服务商以其公布的政策为准。

你可以选择不使用播客功能；需要联网的功能将无法在断网时完整使用。

4. 播客的本地记录与临时音频

节目和单集信息、资源 URL、公开转录全文、播客笔记、播放位置、音量和部分选择状态会保存在本机，封面也会在本地缓存。把播客项目从收藏墙移除，并不等于删除对应的收听记录和笔记。

在支持的 macOS 版本上，文字时间校准使用本机音频及已经安装的听写语言资源，通过系统 SpeechAnalyzer 处理。当前实现不会为此请求云端识别或下载语音模型。校准可能下载一集音频并生成临时转换文件；正常结束任务或关闭播放加载器时会清理相应临时文件，异常退出可能留下残留文件。

5. 分析、诊断和安全

当前应用没有内置广告 SDK 或分析 SDK，也没有向开发者自动发送使用统计或崩溃报告的实现。应用和系统可能在本机记录运行错误等诊断信息；你通过系统设置允许 Apple 收集的诊断、商店记录和你自行发送的材料，分别受相应设置及政策约束。

应用限制书籍中的脚本、远程资源和任意文件路径访问；阅读所需的核心运行库随应用本地提供。播客请求单独访问外部服务。这些措施不代表绝对安全。本地数据没有应用层加密；设备权限、磁盘加密和备份由你及操作系统管理。

6. 保存、删除与数据丢失

阅读和播客资料主要保存在应用管理的本地存储中。你可以在界面中逐条删除书籍笔记或播客笔记。当前版本没有提供覆盖所有书籍和播客档案的一键清空入口；卸载应用也不应被视为已经删除全部支持文件、临时文件或系统备份。

当前实现遇到本地书库索引无法解析或内容校验失败时，会清空并重建书库，可能删除同一存储目录中的书籍、播客和收藏墙资料。因此，应用不能保证资料始终保留到你主动删除；请为重要原文和笔记另行保留副本。

需要完整清理本地资料时，请先退出应用，依据实际安装环境管理应用支持文件和临时文件；如不确定，可通过本文邮箱联系我们。开发者无法远程访问或删除只存在于你设备或个人备份中的资料。撤回文件选择授权不会自动删除已经导入的副本；需要停止播客外联时，请完全退出应用。

7. 主动联系开发者

如果你发送邮件，我们会收到你的邮件地址、正文及你主动附带的文件，并用来答复、排查问题或处理请求。请勿发送无关的书籍全文、敏感笔记或个人照片；可优先提供合成示例。邮件还会经过你和开发者使用的邮件服务商。

联系资料仅在处理请求所需的期间或适用法律要求的期间保留。你可以使用本文邮箱询问、更正或请求删除开发者持有的联系资料；如依法需要保留，我们会说明相应情况。

8. 法律文档网站

本网站本身不添加分析脚本、广告、登录系统、追踪 Cookie 或外部字体。网站计划使用 GitHub Pages 托管；当你访问该托管版本时，GitHub 会为安全目的记录和存储访问者 IP 地址，具体处理见 GitHub Pages 数据说明和 GitHub 隐私声明。这与应用本地书库的处理是两件事。

9. 政策更新与联系

功能或数据处理方式变化时，我们会更新本页。简体中文、繁体中文和英文版本应保持同等内容；如发现表达不一致，请联系我们确认。隐私问题或请求请发送至 BloatMonster@163.com，收件人为 yanhao wu。
